# Privacy-Aware Recommender Lab

A transparent recommendation prototype that demonstrates two privacy-conscious design constraints: use only explicitly allowed preference features and suppress recommendations without a minimum cohort-support threshold.

## Implemented
- item feature representation
- user opt-in preference set
- content-overlap scoring
- minimum cohort-support gate
- deterministic ordering
- deterministic tests

## Scope
This is a small algorithmic lab, not a production recommender, differential-privacy implementation, or formal privacy guarantee.
